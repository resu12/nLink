# nLink 0.3.4 Performance Baseline

Date: March 4, 2026  
Branch scope: 0.3.4 performance engineering only (P1-P6), no protocol/UI changes.

## What Was Measured

### Automated (CI-friendly)

1. Frame size delta (0.3.3 baseline quality proxy vs 0.3.4 default quality)
- Source bitmap: deterministic 640x360 pattern (same generator as encode tests).
- JPEG quality baseline proxy (0.3.3): 75
- JPEG quality current (0.3.4): 70
- Result:
  - Q75 size: `102,374 bytes`
  - Q70 size: `90,927 bytes`
  - Reduction: `11,447 bytes` (`11.18%`)

2. Simulated 2-minute share stability (`Category=Performance`)
- Test: `ScreenSharePipeline_SimulatedTwoMinuteShare_NoHang_NoRunawayMemory_AndContinuousDecode`
- Result snapshot:
  - FramesCaptured: `240`
  - FramesQueued: `240`
  - FramesDropped: `0`
  - ChunksSent: `240`
  - FramesCompleted: `240`
  - Viewer FramesDecoded: `206`
  - DecodeErrors: `0`
  - Memory delta across samples: `5,384 bytes`
  - Memory spread across samples: `5,384 bytes`
- Interpretation: no hang, continuous decode/apply, no runaway memory trend in simulated steady share.

3. Adaptive encode scaling behavior (deterministic tests)
- Slow encode synthetic run triggers scale down to `0.5` and keeps average encode duration above `20 ms`.
- Fast encode synthetic run restores scale back to `1.0` with average encode duration below `12 ms`.

### Manual (RC soak)

Record these in the release checklist:
- P95 end-to-end latency (from DEBUG snapshot logs)
- Average decode time (from DEBUG snapshot logs)
- Average encode time (from DEBUG snapshot logs / encode metrics)
- Average frame size
- CPU usage during 5-minute active share
- Memory delta during 10-minute active share

## Improvement Claims vs 0.3.3

1. Average encoded frame size is lower by `11.18%` on the deterministic reference frame.
2. Simulated sustained sharing remains stable under pacing:
- no hang
- no send backlog growth
- no decode errors
- no monotonic memory growth signal
3. Existing stability regressions remain green in Release after P4/P5.

## Exit Criteria (0.3.4)

- Lower average frame size: met (`11.18%` reduction on deterministic reference frame).
- Lower CPU under sustained sharing: requires manual 5-minute soak capture on target machine.
- No GC spikes: automated simulated share shows flat memory trend; confirm during manual 10-minute soak.
- P95 latency improved vs 0.3.3: capture from DEBUG snapshots during manual soak run.
- No stability regression: maintained in Release test suite.
- No protocol changes: maintained.
