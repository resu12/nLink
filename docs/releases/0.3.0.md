# nLink 0.3.0

## Overview

`0.3.0` delivers the first complete screensharing release on top of the existing nLink bridge transport. The release stays within the frozen architecture: no transport redesign, no JSONL framing change, and no chat contract change.

The work in this release focused on bounded frame streaming, deterministic lifecycle handling, UI clarity, packaging validation, and release hardening.

## Highlights

- End-to-end screensharing is now available in the helper and helpee session shell.
- Frame sending, reassembly, and viewer decode are bounded to avoid unbounded growth under pressure.
- Screenshare sender uses drop and throttling rules instead of trying to deliver every frame.
- Chat and screensharing now coexist with deterministic regression coverage.
- Windows installer, portable ZIP, and `SHA256SUMS.txt` are produced and verified together.

## Upgrade Notes

- `0.3.0` keeps the same transport and bridge architecture as `0.2.x`.
- Installer target path remains `%LOCALAPPDATA%\Programs\nLink Helper`.
- Release assets are under `artifacts/releases/0.3.0/` when built locally.

## Known Limitations

- Audio remains out of scope.
- Screensharing is tuned for stability first, not minimum latency.
- Multi-monitor selection is not exposed.
- JPEG compression uses a fixed quality setting.
- GUI smoke coverage remains Windows-only.
