# nLink 0.3.3

0.3.3 is a stabilization release. No new features were added.

## Screenshare

- Improved shutdown and disconnect determinism in the screenshare send path.
- Tightened backpressure behavior with bounded sender signaling and queue pressure coverage.
- Verified latest-wins decode behavior to keep decode latency bounded under slowdown.
- Hardened helper, helpee, and transport state transitions across stop, disconnect, restart, and rapid toggle paths.
- Added regression coverage for post-stop "stop means stop" behavior.

## Stability

- Expanded deterministic stress coverage for rapid frame load, blocked send, slow decode, and restart or disconnect sequences.
- Added soak-oriented diagnostics and validation guidance for transport, helper viewer, and helpee preview paths.
- Tightened packaging and upgrade validation for the 0.3.3 release path.
