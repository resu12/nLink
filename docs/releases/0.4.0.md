# nLink 0.4.0

## Highlights

- Address-native session connect is now the default model.
- Helper connects using either:
  - direct NKN address, or
  - signed expiring invite token.
- Helpee sharing flow is invite/address-first with QR support.

## Security and Connect Flow

- Canonical identity is `PeerAddress`.
- Invite tokens are signed and expire.
- Validation returns explicit failure types:
  - malformed invite,
  - expired invite,
  - signature verification failure.
- Legacy short-code connect is no longer part of the primary user flow.

## UX Improvements

- Helpee:
  - copy/share invite,
  - copy address,
  - invite expiry countdown with auto-refresh,
  - QR for invite and address.
- Helper:
  - paste from clipboard,
  - scan QR from file/camera (platform-dependent),
  - recent target list.

## Diagnostics and Logging

- Connect attempts now log source:
  - `raw_address`
  - `validated_invite`
- Invalid connect input logs include explicit validation fields for invite parse/verify failures.
