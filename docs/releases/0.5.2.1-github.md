# nLink 0.5.2.1

`0.5.2.1` is a targeted stabilization release for helper/helpee connect reliability on top of `0.5.2`.

## Important updates since 0.5.2

- Fixed helper address bootstrap so helper-bound invites match the real connected helper identity again.
- Added safer recovery when protected per-process NKN seed storage cannot be read.
- Added startup cleanup for stale `identity.instance-*.json` files and matching protected-seed sidecars from dead processes.
- Removed helper recent-address history to simplify the helper connect flow and avoid stale local target reuse.
- Improved helper bootstrap error visibility when protected seed storage is unavailable.

## What stays the same

- Invite-based connect remains the primary flow.
- Helper-bound invites and verified-helper public invite flow remain the release-default path.
- Session protocol and approval/security rules are unchanged.
- File transfer remains single-file only with a `256 MiB` size cap.

## Notes

- After updating, regenerate the helper address and invite before retrying a failed connection.
- Received files are still saved under `%LOCALAPPDATA%\\nLink\\transfers\\incoming\\...` and are not auto-opened.
- Diagnostics export remains best-effort redacted and should be reviewed before sharing.
