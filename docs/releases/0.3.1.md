# nLink 0.3.1

## Overview

`0.3.1` is a stabilization release for the screensharing pipeline introduced in `0.3.0`.

The release stays within the frozen architecture: no transport redesign, no JSONL framing change, no chat contract change, and no UI redesign.

## Highlights

- Screensharing work remains bounded and deterministic under the existing bridge transport.
- Release validation and packaging examples are aligned to the `0.3.1` version line.
- The release scope stays focused on bug fixes, lifecycle hardening, and performance polish.

## Upgrade Notes

- `0.3.1` keeps the same transport and bridge architecture as `0.3.0`.
- Installer target path remains `%LOCALAPPDATA%\Programs\nLink Helper`.
- Release assets are under `artifacts/releases/0.3.1/` when built locally.

## Known Limitations

- Audio remains out of scope.
- Screensharing is tuned for stability first, not minimum latency.
- Multi-monitor selection is not exposed.
- GUI smoke coverage remains Windows-only.

## Verification

- Release assets include `SHA256SUMS.txt`.
- Verify hashes in PowerShell:

```powershell
Get-FileHash .\nLink-Setup-win-x64-0.3.1.exe -Algorithm SHA256
```
