# nLink 0.2.0-beta.1

## Highlights

- More stable session flow for both people in a session
- More predictable end-session behavior
- Diagnostics navigation now returns to the previous screen instead of dropping you into the wrong place
- Cleaner retry and recovery behavior after canceled or failed session attempts

## What to expect

- Starting, canceling, retrying, and ending sessions should now feel more consistent
- Fewer dead-end screens in common helper and helpee flows
- Clearer failure text with a more obvious next step

## Out of scope for this beta

- No WebRTC or screenshare implementation
- No transport architecture changes
- No bridge or protocol redesign

## Diagnostics and support

- If something goes wrong, open `Diagnostics` and include the collected details when reporting the issue
- For current beta limitations and reporting guidance, see [KnownIssues.md](../KnownIssues.md)
