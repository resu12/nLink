# nLink 0.4.2

0.4.2 is a polish release on top of the 0.4.1 hardening work. It keeps the same invite-based remote-help flow and focuses on simplifying approval, cleaning up invite/session UX, and tightening stop/cleanup behavior around chat, screen sharing, and remote control.

## Highlights

- Simpler helpee approval window with a short helper verification code.
- Cleaner invite/session cleanup across end-session and restart flows.
- Better stop/cleanup behavior when screen sharing or remote control is being stopped.

## Included improvements

- Replaced the long technical helper identity in the main approval flow with a short human-verifiable helper code.
- Simplified the approval card copy and removed low-value technical chrome from the default view.
- Cleaned up the helpee invite screen and reduced secondary-action noise.
- Prevented the helper invite panel from expanding on long pasted invites.
- Cleared unsent chat drafts, in-memory chat messages, and the helper invite textbox when starting a new session after an ended one.
- Fixed the first helper reconnect attempt after an ended session so clicking `Connect` no longer drops the pasted invite.
- Tightened helper/helpee cleanup when screen sharing stops during pending or active remote control.

## Notes

- Invite-based connect remains the primary flow.
- Helpee shares an invite with QR, share, and copy actions.
- Helper connects by pasting an invite or scanning a QR code.
- The helper verification code is a human cross-check aid; backend identity/session verification and approval enforcement remain unchanged.
