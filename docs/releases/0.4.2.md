# nLink 0.4.2

0.4.2 is a polish release on top of the 0.4.1 hardening work. It keeps the same invite-based remote-help flow and focuses on simplifying approval, cleaning up invite/session UX, and tightening stop/cleanup behavior around chat, screen sharing, and remote control.

## Highlights

- The helpee approval window is simpler and easier to read.
- Invite and session cleanup are more predictable across end-session and restart flows.
- Screen-share and remote-control stop transitions are tighter and less likely to leave stale UI behind.

## Approval and Invite UX

- Simplified the helpee approval card so the main decision is clearer.
- Replaced the long technical helper identity in the main approval flow with a short human-verifiable helper code.
- Removed redundant approval copy and secondary technical chrome from the default approval surface.
- Cleaned up the helpee invite screen by removing low-value status noise and reducing secondary-action prominence.
- Prevented the helper invite panel from expanding when long invites are pasted.

## Session Cleanup and Reliability

- Cleared unsent chat drafts and in-memory chat messages when a session ends and a new one begins.
- Cleared the helper invite textbox when returning to the post-session waiting state.
- Fixed the first helper reconnect attempt after an ended session so the pasted invite is not lost when `Connect` is clicked.
- Removed redundant verification chrome from connected helper session headers.

## Screen Sharing and Remote Control

- Tightened helper and helpee state cleanup when screen sharing stops during pending remote-control approval.
- Stopping screen sharing on the helpee now clears active remote-control UI more promptly.
- Improved internal tracing and deterministic test coverage for the screen-share stop path.

## Release Assets

- `nLink-Setup-win-x64-0.4.2.exe`
- `nLink-Portable-win-x64-0.4.2.zip`
- `SHA256SUMS.txt`

## Notes

- Invite-based connect remains the primary flow:
  - helpee shares an invite with QR, share, and copy actions
  - helper connects by pasting an invite or scanning a QR code
- The helper verification code is intended as a human cross-check aid. Backend identity/session verification and approval enforcement are unchanged.
