# nLink 0.2.0

## Overview

`0.2.0` finalizes the stabilization work from the RC track: packaging validation, deterministic smoke coverage, and minor UI clarity polish.

There is no transport redesign in this release. The existing bridge and transport architecture remain unchanged.

## Highlights

- Windows installer, portable ZIP, and `SHA256SUMS.txt` are produced and verified together.
- CI covers silent installer install and uninstall on Windows.
- Key smoke and GUI harness paths use bounded deterministic waits instead of fixed sleeps.
- Session header and chat connection status text are consistent across connect and recovery states.

## Upgrade Notes

- In-place upgrade from `0.1.0-beta.5` is supported through the stable Inno Setup `AppId`.
- Installer target path: `%LOCALAPPDATA%\Programs\nLink Helper`

## Known Limitations

- Screensharing remains a minimal Windows-first scaffold.
- Audio remains out of scope.
- GUI smoke coverage is Windows-only.
