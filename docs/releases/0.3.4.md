# nLink 0.3.4

0.3.4 is a stabilization release. No new features were added.

## UI and Layout

- Improved helper and helpee waiting-screen visual balance and hierarchy.
- Removed duplicate waiting status text in the helpee waiting card.
- Refined header alignment and spacing so status and actions align with centered content.
- Reduced back-button visual weight to better prioritize primary actions.

## Stability

- Preserved deterministic screenshare behavior and bounded runtime paths from 0.3.3.
- Kept transport and bridge contracts unchanged.
- Maintained installer and portable packaging flow for release consistency.
