# nLink 0.7.0 hotfix revision 1

**Draft for review — not published.** Proposed tag: `v0.7.0-hotfix.1`. Final CI/artifact validation and signing disposition are pending.

## Fix

Addresses a Windows screen-sharing startup hang that could leave the Helpee preview blank and prevent the Helper from receiving a picture. The persistent software H.264 encoder no longer waits on the sink-writer probe's MP4 finalization before encoding live frames.

Existing input rejection, empty-output checks and sink-writer fallback are preserved. The fallback itself is not claimed to be free of finalization hangs. Session consent, Tuna route authority and transport policies are unchanged.

## Version and downloads

The application and installer continue to report **0.7.0**. This hotfix is distinguished by its separate release tag and checksums, not by the app version alone.

The original [v0.7.0 release](https://github.com/resu12/nLink/releases/tag/v0.7.0), its downloads and `SHA256SUMS.txt` remain unchanged. Planned hotfix attachments are:

Do not mix checksums or packages between the original and hotfix releases. Same-version installer replacement is not yet qualified; installation guidance will be finalized from the exact installer validation.
