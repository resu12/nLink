# nLink 0.2.0-beta.3

## Highlights

- Session shell and standardized header are now the default session UI
- Chat UI is hardened for safer scrolling, ordering, and large-message rendering
- Responsive session layout is enabled by default for narrow and resized windows

## What to expect

- Helper and helpee pages now use the same shell-based session layout
- End session is available from the shared session header instead of duplicated controls
- Resizing between wide and narrow window sizes should keep chat and main session controls usable

## Out of scope for this beta

- No WebRTC or screenshare streaming implementation
- No transport architecture changes
- No bridge or protocol redesign

## Diagnostics and support

- If something goes wrong, open `Diagnostics` and include the collected details when reporting the issue
- For current beta limitations and reporting guidance, see [KnownIssues.md](../KnownIssues.md)
