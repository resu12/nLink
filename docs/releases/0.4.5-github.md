# nLink 0.4.5

0.4.5 is the cumulative release after 0.4.2. It combines the recent screen-sharing improvements, invite/session security hardening, and the simplified helper/helpee connection flow into one release.

## Highlights

- Faster, clearer, and more stable screen sharing.
- Helper-bound one-time invites are now the default release path.
- Simpler helper/helpee bootstrap flow.
- Better diagnostics, secret handling, and transport hardening for release.

## Included improvements

- Screen sharing now has lower delay, better frame pacing, stronger unstable-link behavior, and clearer text/UI defaults.
- Screen-share transport and viewer paths now have better metrics, byte accounting, and resize/display-change recovery coverage.
- Helper identity is bound to the invite/session by default, and one-time issued-secret invites replaced the older shared-secret default.
- Remote control, screen share, lifecycle traffic, and chat now have stronger post-handshake protection and replay resistance.
- Helper and helpee waiting flows were simplified around “share helper address” and “share invite” steps.
- Diagnostics/privacy and local secret storage were tightened for release readiness.

## Notes

- Invite-based connect remains the primary flow.
- Helper shares a helper address, then the helpee enters that helper address, confirms the verification code, and shares a helper-bound invite with QR, share, and copy actions.
- Helper connects by pasting an invite code or scanning a QR code.
- Release diagnostics should show `invite_security_release_ready: Yes` and `invite_security_warning: none`.
- Current release assets live under `artifacts/releases/0.4.5/`.
