# 0.3.3 Manual Validation Checklist

Run this on a desktop session against the `0.3.3` release build.

## Transport

- Start share, stop, then start again.
- Share, disconnect, reconnect, then share again.

## Helper

- View a remote screen, stop, then view again.
- Resize the window repeatedly while viewing.

## Helpee

- Start preview, stop, then start again.
- Toggle preview rapidly several times.

## Confirm

- no freeze or stalled frame updates
- no monotonic memory climb during the session
- stop and disconnect return quickly every time
- no stuck UI state after stop, disconnect, or rapid toggle
