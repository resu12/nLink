# 0.3.0 Freeze

## Feature Freeze

`0.3.0-rc.1` is under feature freeze.

From this point to final `0.3.0`, the screenshare feature set is frozen. Changes must stay inside bug fixes, determinism fixes, packaging fixes, CI hardening, and documentation updates.

No transport redesign, protocol redesign, or UI redesign is in scope for the RC track.

## Do Not Touch

These areas are frozen unless a release blocker forces a versioned follow-up:

- `BridgeProtocolClient`
- JSONL framing
- `ChatEnvelope` contract
- `MultiClient` logic
- session lifecycle state machine

## Allowed Changes

The RC window allows only:

- bug fixes
- test determinism improvements
- performance tuning within the current bounded architecture
- packaging and installer fixes
- documentation and release-process updates

## RC Decision Rule

If a blocker is found:

- fix only the blocker
- keep the protocol additive only
- prefer test hardening and packaging validation over new behavior

If no blocker is found:

- promote `0.3.0-rc.1` to final `0.3.0`
