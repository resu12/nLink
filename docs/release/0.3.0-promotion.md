# 0.3.0 Promotion Criteria

Promotion from `0.3.0-rc.N` to `0.3.0` requires all of the following:

## Required

- [ ] No crash reports during the RC validation window.
- [ ] CI is green for:
- [ ] `Smoke`
- [ ] `ReliabilityGate`
- [ ] `Performance`
- [ ] `GuiSmoke` with at least one clean run.
- [ ] Fresh install validation passed.
- [ ] Upgrade from `0.2.0` validation passed.
- [ ] Manual 5-minute screenshare soak is stable.
- [ ] `VERSION` matches the intended final tag.
- [ ] `SHA256SUMS.txt` has been validated against the published release assets.

## Stop-Ship Triggers

- [ ] Memory leak
- [ ] Deadlock
- [ ] Unbounded CPU
- [ ] Chat regression
- [ ] Screenshare freeze
