# 0.2.0 RC Readiness

Use this checklist before cutting `0.2.0-rc.X`.

## Branching & Versioning

- [ ] RC branch/commit is identified and frozen for release work only.
- [ ] `VERSION` matches the intended RC version.
- [ ] Installer/version metadata matches the intended RC version.
- [ ] Release notes draft is ready for the RC tag.

## Feature Flags And Defaults

- [ ] Default `FeatureFlags` are reviewed for RC-safe behavior.
- [ ] Screenshare flags remain intentionally gated if not ready for RC.
- [ ] No debug-only or experiment-only flags are accidentally enabled by default.

## UX Coherence

- [ ] Home -> Helper/Helpee flows remain banner-first and have no dead ends.
- [ ] Session header, chat panel, and shell layout are consistent between Helper and Helpee.
- [ ] Connected, failed, and ended states do not show contradictory actions.

## Failure Mapping Lockdown

- [ ] `"No one found with that code."` is not overwritten by generic disconnect fallback.
- [ ] `"No response yet."` is not overwritten by generic disconnect fallback.
- [ ] `"Please reinstall."` is not overwritten by generic disconnect fallback.
- [ ] Generic `"Connection lost."` remains fallback-only.

## Screenshare Readiness (Video-Only)

- [ ] Screenshare remains video-only; no audio work is included.
- [ ] Non-Windows behavior remains safe when capture is unsupported.
- [ ] Preview/start-stop lifecycle is clean and does not leave stale frames behind.
- [ ] Transport-gated screenshare paths remain bounded and latest-frame-wins.

## Performance & Resource Sanity

- [ ] No obvious memory growth across repeated connect/disconnect cycles.
- [ ] Chat and screenshare paths do not leave background tasks running after stop/end.
- [ ] Resource sanity checks pass for the RC candidate.

## Testing Gates

- [ ] `dotnet build -c Release` passes.
- [ ] `dotnet test -c Release --filter Category=Smoke` passes.
- [ ] GUI smoke run is completed on Windows for the RC candidate.
- [ ] BetaReadiness and existing reliability/resource gates remain green.

## Packaging & Distribution

- [ ] Portable ZIP is built for the RC version.
- [ ] Installer is built for the RC version.
- [ ] Checksums are generated and stored with the release artifacts.
- [ ] Release artifact names match the RC version exactly.

## Logging & Diagnostics

- [ ] Diagnostics page still opens and returns correctly.
- [ ] Diagnostics output is copyable and useful for RC triage.
- [ ] No new raw exceptions or technical IDs appear in the main UI.

## Manual RC Acceptance Run (Scripted)

- [ ] Home -> Helpee -> Helper -> Connect -> Chat works on Windows.
- [ ] Helper -> Diagnostics -> Back returns to Helper.
- [ ] Helpee -> Diagnostics -> Back returns to Helpee.
- [ ] End session, retry, wrong code, approval timeout, and reinstall-required paths were exercised.

## Do Not Ship RC If…

- [ ] Any smoke gate is red.
- [ ] Helper/Helpee can get stuck without a valid next action.
- [ ] Failure mapping regressed to generic fallback text.
- [ ] Packaging output does not match the intended RC version.
- [ ] Screenshare leaves stale UI, crashes, or platform-specific breakage when flags are enabled.

## RC Cut Steps

- [ ] Confirm this checklist is complete in the RC readiness issue.
- [ ] Create the RC commit/tag.
- [ ] Build portable ZIP, installer, and checksums from that commit.
- [ ] Publish the GitHub pre-release with notes and artifacts.
- [ ] Run one post-publish install/sanity check from the shipped installer.
