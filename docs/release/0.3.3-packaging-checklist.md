# 0.3.3 Packaging and Upgrade Checklist

Run this on a clean Windows VM or a disposable local user profile.

## Upgrade Path

1. Install `0.3.2`.
2. Launch the app once.
3. Upgrade in place to `0.3.3`.
4. Launch again.

## Functional Sanity

1. Start a session as helpee.
2. Start preview sharing.
3. Stop preview sharing.
4. Start a session as helper.
5. View a remote screen.
6. Stop viewing / end the session.
7. Exit the app.
8. Relaunch the app.

## Verify

- app launches without a crash after install and after upgrade
- expected packaged assets are present
- config is still present and readable after upgrade
- no missing bridge/runtime files
- helpee preview start/stop works
- helper view start/stop works
- relaunch succeeds after clean exit
- logs are clean enough for release review:
  - no startup crash
  - no repeated unhandled exception pattern
  - no screenshare stop/disconnect errors during the checklist run

## Existing Packaging Validation

If release artifacts were built locally, also run:

```powershell
dotnet build .\nLink.sln -c Release
dotnet test .\nLink.sln -c Release
powershell -ExecutionPolicy Bypass -File .\build\verify-package-manifest.ps1 -StageDir .\artifacts\portable\nLink\win-x64 -ManifestPath .\installer\package-manifest.win-x64.txt
powershell -ExecutionPolicy Bypass -File .\build\verify-package-manifest.ps1 -StageDir .\artifacts\portable\helper\win-x64 -ManifestPath .\installer\package-manifest.win-x64.txt
```
