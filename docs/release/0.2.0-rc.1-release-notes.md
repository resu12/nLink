# nLink 0.2.0-rc.1

## Overview

`0.2.0-rc.1` is a release candidate focused on stabilization, packaging validation, and deterministic test hardening ahead of the final `0.2.0` release.

This RC does not include a transport redesign. The existing bridge and transport architecture remain unchanged.

## Highlights

- Packaging hardened for the Windows installer and portable ZIP, with release-asset verification and bundled checksums.
- CI now covers silent installer install/uninstall smoke on Windows.
- Deterministic test improvements removed fixed sleeps from key smoke and GUI harness paths.
- Minor UI clarity polish keeps session header status text and chat connection pill text consistent.

## Upgrade Notes

- In-place upgrade from `0.1.0-beta.5` to `0.2.0-rc.1` is supported through the stable Inno Setup `AppId`.
- Installer target path: `%LOCALAPPDATA%\Programs\nLink Helper`

## Known Limitations

- Screensharing remains a minimal scaffolded path and is still Windows-first.
- Audio remains out of scope.
- GUI smoke coverage is Windows-only.

## Verification

- Release assets include `SHA256SUMS.txt`.
- PowerShell checksum example:

```powershell
Get-FileHash .\nLink-Setup-win-x64-0.2.0-rc.1.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```
