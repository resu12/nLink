# 0.3.3 Screenshare Soak Runbook

Run on a Windows desktop session with the app visible. Target 30-60 minutes per scenario.

## A. Transport Send Soak

Active signal:
- `TransportScreenShareCoordinator.IsActive`

Actions:
- Start transport screenshare and confirm `IsActive == true`.
- Let it run for 30-60 minutes.
- Resize the window every 5-10 minutes.
- Do one explicit stop/start cycle.
- Do one disconnect/reconnect cycle.

Record:
- start and end timestamps
- memory trend every 5-10 minutes
- any visible freeze/stall
- stop latency
- disconnect latency
- relevant debug snapshot lines or counters:
  - `FramesQueued`
  - `FramesDropped`
  - `ChunksSent`

## B. Helper Viewer Soak

Active signal:
- `ScreenShareViewerViewModel.IsActive`

Actions:
- Start helper viewing and confirm `IsActive == true`.
- Let it run for 30-60 minutes.
- Resize the window every 5-10 minutes.
- Do one remote stop/start cycle.
- Do one disconnect/reconnect cycle.

Record:
- start and end timestamps
- memory trend every 5-10 minutes
- any frozen last-frame event
- stop/disconnect latency until `IsActive == false`
- relevant debug snapshot lines or counters:
  - viewer `FramesDecoded`
  - viewer `DecodeErrors`
  - latest render/apply timestamp if available

## C. Helpee Preview Soak

Active signal:
- `HelpeePageViewModel.IsScreenSharingPreviewActive`

Actions:
- Start preview sharing and confirm `IsScreenSharingPreviewActive == true`.
- Let it run for 30-60 minutes.
- Resize the window every 5-10 minutes.
- Do one toggle stop/start cycle.
- Do one disconnect/reconnect cycle.

Record:
- start and end timestamps
- memory trend every 5-10 minutes
- any preview freeze/stall
- stop latency until `IsScreenSharingPreviewActive == false`
- relevant debug snapshot lines or counters:
  - preview `FramesDecoded`
  - decode task active count if sampled
  - any debug failure lines

## Pass Criteria

- no freezes longer than a few seconds
- stop and disconnect return promptly
- active signal returns to `false` after stop/disconnect
- memory trend is flat or slowly varying, not monotonically growing
