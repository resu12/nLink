# Canonical-cycle GUI fixture work budget

Only the exact Debug canonical-cycle GUI fixture receives a fixed 30,000 ms
cumulative work ceiling. Normal tool compilation and every other profile retain
15,000 ms. This is an explicitly authorized fixture resource-policy revision,
not a runtime-authority or acceptance-rule change.

The preceding run spent 14.6482052 s before parent preparation, published facts
at 14.9904675 s, and recorded a seal-scope rejection at acknowledgment entry at
15.001011 s. It copied 172,628,324 semantic bytes and processed 216,652 rows.
The nested false operand was not separately recorded, so that run is not
reclassified as a proven budget-only failure. The deterministic controls cover
the same nested deadline mechanism independently.

Thirty seconds is a fixed two-times observed-work allowance. It leaves finite
headroom for larger admitted inputs and host variation, not a worst-case or
throughput guarantee. Input maxima still need not complete on every machine;
expiry fails closed. This ceiling is not added to the old 15 seconds.

The test-only compiler loader selects this policy only with a nonempty GUI
passive-diagnostic output directory and all existing exact scope fields:
attempt-dispatch 1, Debug worker configuration, canonical-cycle-v1, the original
full canonical-tail late-publication scenario, writer-valid wrapper, valid
parent, canonical-tail-late-publication primary, and no diagnostic-custody
profile. Release, missing/changed/case-altered scope, the ineligible control and
non-GUI compilation never receive it. There is no public numeric parameter.

The projection changes exactly one private-copy constant, from 15000 to 30000.
It records source/projected hashes and exact reverse-text equality, separately
from the subsequent passive diagnostic projection. No original tool file is
edited. Every entry, nested scope, native resource and exit predicate remains.
Ledger creation, adoption, sealing, parsing, copy and final handoff share the
same original Stopwatch and already-counted work; no reset, refill, excluded
work, cached currentness, source reopen or retry is introduced.

Producer/attachment 20 s, source capture 60 s, retained active 180 s, retained
wall 3600 s, and the outer fixture 4320 s are unchanged. Carrier, read/handoff,
scenario/grace/hard deadlines, input/scalar/metadata/candidate/operation/visit,
retry and concurrency limits remain unchanged. Coordinator-issued DTOs/tokens
remain the sole runtime authority. Budget eligibility grants no ownership,
route, repair, liveness, commit or publication authority.

Focused controls use stopped original clocks at exact limits and plus one,
the real outer Current and nested LedgerOriginCurrent methods, expiration
inside a nested callback and at exit, revocation, retirement/no revival,
continued cumulative work and unchanged false authority flags. Synthetic
elapsed injection is a small-test control, not scale or live evidence.
A fresh composition must still prove acknowledgment, commit and subsequent
native analysis before candidate freeze. Earlier failed attempts remain failed.
